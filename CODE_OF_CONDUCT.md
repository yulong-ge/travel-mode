# Contributor Covenant Code of Conduct

We are committed to making participation in this project a harassment-free experience for everyone.

## Our standards

Examples of behaviour that contributes to a positive environment include respect, welcoming diverse viewpoints, constructive feedback, and accepting responsibility for mistakes. Unacceptable behaviour includes harassment, discrimination, personal attacks, public or private abuse, and publishing private information without permission.

## Enforcement

Report unacceptable behaviour through a GitHub issue or GitHub Security Advisory. Maintainers will review reports, protect the reporter's privacy, and take action they consider appropriate, including a warning or removal from project spaces.

This text follows Contributor Covenant 2.1. See https://www.contributor-covenant.org/version/2/1/code_of_conduct/ for the full standard.
